# ExpenseTracker (Flutter, offline-first)

Offline personal finance app. No backend is required for core flows; optional group sync uses anonymous Firebase.

## Principles
- **Offline-first:** Drift/SQLite local DB. Share/OCR, exports and group sync are optional paths; none block manual entry.
- **Flexibility:** budgets (N buckets), categories (`space=level, -=item`), sources/dests, all user-definable. No hardcoded enums in DB.
- **Dual-amount ledger:** every money event stores `actualAmount` (bank impact) + `budgetImpact` (budget impact). Lending/split/transfer differ only in these two numbers.
- **Decoupled modules:** `lib/features/*` depend only on `lib/core/*`. One feature failing never blocks another.

## Optional Firebase group sync
Groups work offline and personal expenses never leave the phone. Group sync is the
only network path: it mirrors group payloads (members, expenses, pay-ups) to
Firestore so different phones can share a group by code.

- **Auth:** anonymous Firebase Auth — no email, Google account or OAuth consent.
- **Invite secret:** each group has an 8-character code (`ET-XXXXXXXX`). Anyone
  with the code can fetch and join that one group; signed-in users cannot list
  groups they are not members of.
- **Local-first:** Drift stays authoritative. Sync pulls and merges remote rows
  into local, then pushes in a Firestore transaction, so two phones adding rows
  at once keep both. Only group data is stored — never the ledger or backups.
  Members are unioned too, so a person removed on one phone can be re-added by
  another phone's older copy; expenses/pay-ups have no delete path to lose.
- **Deploy rules:** `firebase deploy --only firestore:rules` (`.firebaserc` defaults to `expensetracker-e22db`).
  Enable **Authentication → Anonymous** once in the Firebase console.
- **Config:** `lib/firebase_options.dart` and `android/app/google-services.json`
  are generated by `flutterfire configure`; `firebase.json` points at
  `firestore.rules`. The group owner must tap **Sync now** once so the group
  reaches Firebase; after that joiners pull it by code.

Sync starts after you first open **Groups**, a group, or **Settings**, then runs
while the app is open; use **Sync now** any time. There is no background service
and no app server.
